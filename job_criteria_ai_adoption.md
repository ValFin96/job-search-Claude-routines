## HARD FILTERS

| Filter | Value |
|---|---|
| Location | Sydney, NSW or Remote (Australia-wide accepted) |
| Work arrangement | Remote or hybrid only. Flag any fully in-office role. |
| Salary | $120,000+ AUD where listed. If not listed: pass through and flag. |
| Role type | Business/consulting/enablement side ONLY. No software engineering. |
| Technical depth | Must NOT require hands-on coding, model building, or ML engineering. Tools usage (Claude, ChatGPT, Copilot, n8n, Zapier) is fine. Building the tools is not. |

## SCORING BONUSES (used for scoring -- not hard filters)

| Signal | Bonus |

| Mentions AI governance, responsible AI, or AI policy | +0.3 |

| Flexible hours or remote-first | +0.3 |
| Government or large enterprise (structured AI rollout) | +0.3 |

## SCORE THRESHOLD

- Score 7.0 or above: Send Telegram alert with full details
- Score 5.0-6.9: Log in report as "Below threshold -- review manually"
- Score below 5.0: Log as "Rejected" and discard
